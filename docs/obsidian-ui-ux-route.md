## UI/UX Design

**ผู้ดูแล:** AI Agent "UI" | **โฟลเดอร์:** `D:\claude project\UI\UI GAME` | **Stack:** HTML + CSS + Vanilla JS, Chart.js 4.4.1, Tesseract.js 5.0.5 (CDN, มี SRI)

**แนวคิดดีไซน์** ("สมุดบัญชีดิจิทัล"): ตัวเลขเป็นพระเอก (Geist Mono), เลย์เอาต์ไม่สมมาตร 7/5 บนเดสก์ท็อป คอลัมน์เดียวบนมือถือ, สีเดียว (เขียว `#0F7A5C` / มืด `#3FB68B`) + สีรายจ่ายสื่อความหมาย (`#B24A5E` / `#D8758A`), สลับโหมดสว่าง/มืดได้ ใช้ฟอนต์ Outfit + Noto Sans Thai + Geist Mono. Skills ที่ใช้เป็นแนวทาง: design-taste-frontend-v1, frontend-ui-engineering, frontend-design, improve-animations.

**ข้อสังเกต/ที่ยังเปิดอยู่**
- เส้นขอบช่องกรอกตัดกับพื้นต่ำกว่า 3:1 (เฉพาะ non-text) — รอตัดสินใจเข้ม `--line`
- เดสก์ท็อป: คอลัมน์ขวาว่างใต้ช่องสลิปเมื่อประวัติยาว (balance/slip ใช้แถวเดียวกัน) — รอตัดสินใจปรับ layout
- Tesseract ดาวน์โหลด worker/ภาษาจาก CDN ตอนรันโดยไม่มี SRI; รีโหลดหน้าระหว่าง OCR อาจขึ้น error ในคอนโซลจากไลบรารี
- Reduced-motion ยังไม่ได้ทดสอบด้วยการตั้งค่าระบบจริง
